# TrueNAS Private Cloud Storage

Repository ini digunakan untuk menyimpan dokumentasi dan script yang digunakan dalam instalasi serta pengujian performa TrueNAS pada proyek Private Cloud Storage berbasis NAS.

## Tugas

- Instalasi TrueNAS.
- Konfigurasi awal TrueNAS.
- Konfigurasi storage.
- Konfigurasi dataset dan shared folder.
- Konfigurasi SMB.
- Pengujian upload dan download file.
- Pengujian penggunaan CPU dan RAM.
- Dokumentasi hasil pengujian performa TrueNAS.

## Sistem yang Digunakan

- TrueNAS
- SMB
- Windows sebagai client

## Pengujian

Pengujian performa dilakukan dengan melakukan transfer file antara client dan TrueNAS melalui jaringan.

Parameter yang diamati:

1. Waktu transfer file.
2. Kecepatan transfer.
3. Penggunaan CPU.
4. Penggunaan RAM.
5. Stabilitas sistem selama proses transfer.
